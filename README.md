## Project setup
```
yarn install
```

### Compiles and hot-reloads for development
```
yarn serve
```

### Compiles and minifies for production
```
yarn build
```
Use Node 12: `node-sass` 4.13 has no prebuilt binaries for newer versions.
CI builds `dist/` on every push and keeps it as a workflow artifact.
