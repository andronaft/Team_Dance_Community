# Team Dance Community: API requests

[![validate](https://github.com/andronaft/Team_Dance_Community/actions/workflows/validate.yml/badge.svg?branch=katalon)](https://github.com/andronaft/Team_Dance_Community/actions/workflows/validate.yml?query=branch%3Akatalon)

Katalon Studio project with requests for the REST API from the `rest` branch,
imported from Postman. Open `tdc.prj` in Katalon Studio.

The requests expect the backend on `http://localhost:8080`, see the `rest`
branch README for how to start it.

CI checks that the project files are well-formed XML and that no Katalon
TestOps login token is committed.
